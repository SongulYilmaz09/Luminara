# 🔮 Luminara: Journey of Lost Lights

> A fantasy puzzle adventure mobile game built with Unity and C#.

Luminara is a story-driven fantasy puzzle game designed for mobile platforms.

Players explore a magical world, solve light-based puzzles, unlock new regions, discover hidden secrets, and follow an evolving story.

The game is designed as a continuously expanding experience, with new chapters, characters, puzzles, and story content planned through future updates.

---

## 🎮 Game Overview

**Genre:** Fantasy • Puzzle • Adventure • Story

**Platforms:** iOS • Android

**Game Engine:** Unity

**Programming Language:** C#

**Backend:** Firebase

**Development Status:** Prototype / In Development
